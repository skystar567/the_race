# 任务 13：课程资料包验收计划

**状态：C 代码审核未通过，任务 13 未接入主线。以下没有已通过项。** 改编自成员 C 的 [导出材料](https://github.com/skystar567/the_race/blob/2924f0961e94d8a22bbdafc554d601df1665d83c/docs/member-c/export-checklist.md)。旧交付收到 ZIP/HTTP 200 只能说明生成了文件，不能证明链接、历史依据、冲突和并发一致性满足规格。

## 建议包结构

```text
README.md
manifest.json
knowledge/index.md
knowledge/concepts/<concept-id>.md
relations.md
notes/index.md
notes/<note-id>.md
materials/README.md
materials/<material-id>.md
sources.md
conflicts.md
```

结构可随公开接口适配，但必须能在应用外浏览；`manifest.json` 应记录课程、固定知识版本、笔记修订/版本、文件清单与哈希。

## 必须验证

- [ ] **所有引用可用**：知识页和笔记正文里的 `snippet:` 链接重写为包内相对链接及真实锚点，不能只在末尾追加一份可点击来源列表。逐页解析链接、文件和锚点，不允许残留应用专属引用或无说明的失效链接。
- [ ] **关系引用完整**：只被关系引用、没出现在知识点或笔记中的原文也进入来源索引；每条边保留 `contains/precedes/contrasts` 与 `source/suggested`。
- [ ] **旧笔记依据可追溯**：使用笔记记录的 `version_id` 找到当时引用和原文片段，不能只查询当前快照。构造笔记仍引用旧版本片段、当前版本不再含该片段的情况，打开包仍能定位依据。
- [ ] **主线 09 冲突结构**：从每个 `concept.conflicts` 读取冲突，不依赖旧交付的顶层 `snapshot.conflicts`；保留冲突双方陈述、上下文与各自引用，区分同名不同义与未解冲突。
- [ ] **并发事务快照**：通过公开导出读取接口在一致的数据库读事务/快照中固定当前知识版本、完整笔记正文、引用、修订、拓展标记及资料清单。生成 ZIP 时可使用已固定的数据；不能依次读当前版本、笔记列表、每条笔记造成不同时刻混合。
- [ ] **并发回归**：导出读取过程中编辑笔记并发布新版本，结果必须是一致时点的内容，不能混合新正文与旧引用、漏掉某次修订或错配 manifest。事务边界应可测试，不以单用户场景省略。
- [ ] **个人内容保留**：读取完整笔记详情而非列表摘要，保留用户编辑正文、引用、模型拓展标记和待核对提示，不用新模型生成内容覆盖。
- [ ] **原始资料保留**：导出 Markdown 与导入原文逐字节一致；来源索引记录资料名、行号、原文；不改写教材补全缺图。
- [ ] **缺图明确**：保留缺图说明及原位置，不能把缺少的图片声称已导出或生成虚假图像。
- [ ] **课程隔离与完整性**：文件均来自本课程；manifest 中的计数、版本与 SHA-256 和 ZIP 实际内容一致。
- [ ] **应用外验收**：目标电脑解压后，从 README/索引进入知识页、关系、笔记和原文，检查中文文件名、锚点、相对链接及历史引用，记录实际耗时、包体积和失败项。

上述案例需要在修复并适配主线笔记/版本接口之后执行。现有代码返回 ZIP 或测试只解析追加的来源列表，都不能替代正文链接与事务快照的验证。
