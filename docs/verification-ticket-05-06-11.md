## 已实现

### 05 个人笔记

- `campus/notes.py`：手写笔记创建、编辑保存、列表、详情、从知识点/已完成回答/拓展解释生成。
- 笔记保存 `version_id`、来源类型与 id、引用、拓展标记、修订号；正文 Markdown 与渲染 HTML。
- 编辑使用修订号乐观锁：旧修订返回 409，不覆盖他处保存的正文。
- 笔记独立于知识点页面与课程知识存储；知识更新不写笔记表。
- `web/notes.tsx`：笔记列表、编辑器、预览、保存、引用打开、需检查依据提示。

### 06 主动拓展解释

- `campus/expansions.py`：仅在学生主动请求时调用 Flash；从已完成回答或知识点生成。
- 输出强制加上 `> 模型补充（超出课程资料）` 标记；失败保存为 `failed` 状态与错误原因，不伪装成完成解释。
- 拓展只写 `expansion` 表，不写课程知识；可生成个人笔记并保留 `expansion` 标记。
- 前端在知识点面板与已完成问答中提供“获取资料外拓展解释”，成功后显示标记与“保存为个人笔记”。

### 11 更新时保留

- 回答创建时固定 `version_id`；旧回答仍通过该版本打开原文。
- 笔记保存创建时的版本与引用；编辑不改变来源信息。
- `needs_review` 只在引用片段缺失或引用文字在当前版本中变化时提示；未变化的笔记不标记过期。
- 笔记正文、修订号在第二版本发布后保持不变；不自动改写个人内容。
