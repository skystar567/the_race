# Triage Labels

本项目采用默认分诊标签，在本地规格和任务的 `Status:` 行记录。

| Canonical role | Tracker label | 含义 |
| --- | --- | --- |
| needs-triage | needs-triage | 等待维护者评估 |
| needs-info | needs-info | 等待补充信息 |
| ready-for-agent | ready-for-agent | 规格充分，可交由 agent 实现 |
| ready-for-human | ready-for-human | 需要人工实施 |
| wontfix | wontfix | 不计划处理 |

技能提及某个分诊角色时，使用表中对应的标签。
