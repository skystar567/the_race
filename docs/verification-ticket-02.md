# 任务 02 实现与验证记录

日期：2026-10-25。范围：把一小节资料整理成可浏览、可追溯的课程知识版本，并提供版本化读取、图谱界面、任务状态与失败处理。成员 B 负责。

**结论：代码闭环、确定性测试、真实 DeepSeek 调用与真实模型页面均已验证；真实教材正文缺失，因此第 7 项“人工核对真实样本”不勾选。** 真实模型验收使用一小段验收短文（非教材原文），受控模型响应只用于测试。

## 已实现

- 统一 DeepSeek Responses 适配器：`deepseek-flash`、结构化 JSON Schema、思考模式、SSE 终态、错误分类（配置/鉴权/限流/网络/截断/空输出/结构无效）。
- 固定六步：`ingest → extract → integrate → render → validate → publish`；成功步骤持久化，失败可重试。
- 整理范围：资料或章节，校验课程归属；单次 60,000 字符上限，超出明确拒绝。
- 校验：引用片段在范围内且文字可定位；章节归属有该章节内引用；关系端点/类型/方向/来源；页面与知识点一一对应；发布前重新校验整份快照。
- 版本化存储：候选/已发布/当前指针；发布在写事务内完成并带 worker 租约栅栏；同一任务重复发布幂等。
- 独立 worker：SQLite 全局租约、心跳、有限重试、步骤复用、未预期异常记录为失败而不终止进程。
- HTTP：任务创建/列表/详情/重试，版本列表，知识快照，知识点页面与原文；读取绑定 `version_id`。
- 前端：Cytoscape 图谱（章节/知识点，包含/前置/对比，来源与推断标记）、知识点列表与页面、引用弹窗、任务步骤与失败原因、整理范围选择、已整理/未整理状态同步。
- Windows 启动脚本 `scripts/start.ps1`（ASCII 输出，避免 PowerShell 5.1 编码问题）。
