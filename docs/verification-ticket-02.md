# 任务 02 实现与验证记录

日期：2026-10-25。范围：把一小节资料整理成可浏览、可追溯的课程知识版本，并提供版本化读取、图谱界面、任务状态与失败处理。成员 B 负责。

**结论：代码闭环与确定性验收已完成；真实 DeepSeek 调用与真实教材验收未完成。** 任务 02 的 7 项验收条件中勾选 2—5 项；1、6、7 因缺少凭据或真实教材保持未勾选，原因逐项写在下面。受控模型响应与合成长文只用于测试，**不代表真实模型效果**。

## 已实现

- 统一模型适配器：`POST /responses`、`deepseek-flash`、结构化 JSON Schema、思考模式、SSE 终态解析、错误分类（配置／鉴权／限流／网络／截断／空输出／结构无效）。
- 固定流程：`ingest → extract → integrate → render → validate → publish`，成功步骤持久化，失败可重试。
- 整理范围：按资料或章节选择，校验课程归属，单次 60,000 字符上限，超限明确拒绝。
- 内容校验：引用片段必须在范围内且文字可定位；章节归属必须有该章节内的引用；关系端点、类型、方向与来源标记；页面与知识点一一对应；发布前重新校验整份快照。
- 版本化存储：候选版本 + 已发布版本 + 当前指针；发布在写事务内完成，并带 worker 租约栅栏；同一任务重复发布幂等。
- 独立 worker：SQLite 全局租约、心跳、有限重试、步骤复用、未预期异常记录为任务失败而不终止进程。
- HTTP：任务创建／列表／详情／重试，版本列表，知识快照，知识点页面与原文片段；全部读取绑定 `version_id`。
- 前端：Cytoscape.js 图谱（章节／知识点，包含／前置／对比，来源与推断标记）、知识点列表与页面、引用弹窗、任务步骤与失败原因、整理范围选择、未整理状态。
- Windows 启动脚本 `scripts/start.ps1`（ASCII 输出，避免 PowerShell 5.1 编码问题）。

## 对继承实现的审查与修复

| 待审查点 | 处理 |
| --- | --- |
| 是否错误信任 `validated` 标记 | 发布前重新执行 `validate_snapshot`，不读取该标记做判断；快照篡改测试通过 |
| 发布与任务完成之间的中断窗口 | 发布指针切换后任务仍为 `running` 时，再次领取会幂等返回已发布版本并补写完成状态；测试模拟该崩溃点 |
| 租约检查与发布之间的失效窗口 | 租约栅栏作为回调放进发布写事务内执行，事务外无法再切换指针 |
| 重试／重复启动／中断导致重复发布 | 同一 `task_id` 复用 `knowledge_version`；`publish_task` 对已发布版本直接返回；测试断言版本数仍为 1 |
| 未预期异常导致 worker 退出 | 捕获所有异常，记录 `internal` 失败并继续轮询；测试注入 `RuntimeError` |
| JSON 快照是否满足后续读取 | 读取接口按版本封装；快照自包含章节、片段、概念、关系。拆表迁移留给 08，需保留旧快照可读 |
| 章节归属、引用列表与页面内引用一致 | 三者都从同一批已验证引用构建；页面内 `snippet:` 必须先声明 |
| 长表达式与重复查找 | 抽取 `citation_fragment_id`、`citation_inside_chapter`、`chapter_title` 等辅助函数，移除重复 `next()` 链 |
| API 中使用 `assert` | 改为明确的 404 |
| 重试时在写事务里另开连接读指针 | 改为在同一连接内读取，避免锁竞争 |
