# 校园课程学习助手：方案讨论记录

本文件记录产品方案的已确认选择与决策依赖。Q1—Q22 均已确认，本轮产品方案讨论完成；尚未进入实现。完整用户流程和验收标准见 [产品方案](product-plan.md)。

## 已确认

- **项目目标（Q1）**：比赛项目。用户描述的交付底线是可运行 Demo。
- **主要使用者与使用方式（Q2）**：学生独立创建和管理个人课程学习空间，开始使用不依赖老师参与。
- **主要使用场景（Q3）**：日常课后理解课程内容、整理知识与笔记。
- **验证材料（Q4）**：用户已有计算机操作系统相关教材的 Markdown 文档。已完成目录和候选教材抽查，演示书籍与章节已在 Q17 确认。
- **LLM Wiki 约束（Q5）**：采用持续组织和维护关联知识的思想，不绑定特定现成项目；支持导出 Markdown 知识库，包含知识页面、页面关联和来源信息。
- **第一版输入（Q6）**：只支持 Markdown，使用现有教材验证完整流程；PDF 留作后续扩展。
- **知识展示（Q7）**：知识图谱是核心展示方式，同时保留知识点页面。
- **学习建议（Q8）**：依据学习目标、当前章节和知识关系推荐路线，并在图谱中突出显示建议阅读的知识点及顺序；第一版不纳入短测诊断、长期掌握度评估或复习调度。
- **比赛要求（Q9）**：用户说明无额外要求。尚未提供截止日期或开发时间预算，本阶段不据此推定排期。
- **图谱语义（Q10）**：使用章节与知识点两类节点，以及包含、前置、对比三类关系。前置关系表达学习建议，不能仅由章节顺序推定；需要依据或明确标为系统建议。例题、公式暂不作为独立节点。
- **图谱浏览（Q11）**：默认展示章节概览，展开章节后浏览知识点；选择知识点后可查看跨章节关联。打开知识点详情时保留图谱位置，详情支持阅读解释、查看来源和提问；需要时提供全图视图。
- **问答依据（Q12）**：默认依据上传资料回答，关键结论可定位到原文章节或段落；资料不足时明确说明。学生可主动选择拓展解释，模型补充须明确标注，不伪装成教材内容，也不自动写入课程知识库；图谱中的推断关系同样需要标识。
- **追加资料（Q13）**：第一版支持向同一课程追加 Markdown，并更新已有图谱和知识点页面。同一概念按含义整合不同来源，新概念形成新节点；相互矛盾的表述并列展示并保留来源，不能仅凭同名合并概念。
- **个人笔记（Q14）**：知识点页面随资料更新；学生可将选中的知识点、解释或问答生成个人笔记并编辑保存。更新课程知识库时保留个人笔记，相关来源发生变化时提示学生检查。
- **问答范围（Q15）**：默认使用当前课程的全部知识库，所选知识点是讨论焦点；学生可以限定某份资料或某个章节，界面显示当前范围，回答提供具体来源；切换课程时问答范围同步切换。
- **教材位置（Q16）**：用户提供 `/root/pdfclean/cleanpdf/书籍合集`，只读检查发现 16 份 Markdown，详见下方教材检查记录。
- **演示材料与范围（Q17）**：采用《计算机操作系统（第四版）》，演示覆盖第 2 章“进程的描述与控制”及第 3 章死锁部分（3.5—3.8）。其他章节可继续添加；区分已导入和已整理，不能将未整理内容表现为已经处理完成。
- **内容能力（Q18）**：第一版支持文字、公式和代码展示，明确标注缺失图片；必须读图才能回答的问题提示资料不足。不纳入图片理解，也不承诺自动修复全部识别错误。
- **演示组织（Q19）**：预先通过真实处理流程构建基础知识库，现场追加一份短 Markdown，展示知识新增、页面更新与来源变化，再进行问答、笔记和学习路线操作；预构建内容保留重新构建入口。
- **纠错入口（Q20）**：学生可针对知识点或关系反馈问题，系统回查资料并重新整理相关内容，保留个人笔记。自由绘制、任意编辑整张图谱不属于第一版。
- **导出范围（Q21）**：导出当前课程的完整资料包，包括知识页面、关系索引、个人笔记，以及已导入的原始 Markdown；保持页面链接、来源引用和模型拓展标记可用。
- **更新过程（Q22）**：追加资料或纠错重新整理期间，已有知识库继续可用；成功后统一更新相关图谱、知识点页面与来源，并展示变化；失败时保留旧内容并允许重试，个人笔记始终保留。首次构建失败时明确显示尚未生成可用知识库。
- **讨论阶段**：先确认方案，再考虑实现。

## 原始需求与边界

用户希望上传课堂 PDF、教材或书籍，由 LLM 整理结构化知识库，支持基于知识库的问答、学习笔记与学习建议。第一版已收敛为 Markdown 输入、知识图谱与知识点页面、带依据的问答、可编辑个人笔记、基于知识关系的学习路线，以及追加资料后的知识更新。

PDF 是长期产品方向中的输入形式，不是本次 Demo 的必交能力。第一版的学习建议不声称已通过测试发现学生的薄弱点。

- 仍有扫描或清理残留，例如第 2717 行的数字串，以及第 5108 行的章节标题误字。
- `操作系统概念.md` 的正文实际为英文 OSTEP；`操作系统设计与实现（第三版）.md` 实际为下册。
