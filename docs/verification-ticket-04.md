## 范围与检索

- 默认范围是**当前已发布知识版本覆盖的全部已整理内容**；可按资料或章节收窄。所选资料/章节必须属于该版本，否则 422。未整理的原始资料不参与问答，这是与“当前课程全部资料”字面表述的已知差异，原因是引用必须版本固定。
- 提问焦点只是上下文，不把证据限制为该知识点。
- 检索先做确定性匹配：概念名、别名、中文二字词（覆盖“进程”“线程”）、定义/页面文本、图谱一跳邻接；没有命中时让 Flash 从允许的概念目录选择，程序只接受目录内的 id。
- 不引入向量检索；代表问题暴露召回缺口时再补。

## 流式与状态

`POST /api/courses/{course_id}/answers/stream` 返回 SSE：

| 事件 | 内容 |
| --- | --- |
| `start` | answer_id、version_id、范围、焦点、证据数、缺失图片数、检索方式 |
| `delta` | 增量文本 |
| `done` | 完整回答对象（状态、引用、HTML、错误） |

状态：`generating`、`completed`、`insufficient`、`citation_failed`、`interrupted`、`failed`。只有引用全部合法且至少一条时才是 `completed`；引用未提供片段为 `citation_failed`，没有引用为 `insufficient`；流中断或客户端中止为 `interrupted`。未完成内容不会标成完成答案。

- 回答行保存 `version_id`、问题、范围、焦点、正文、引用（片段 id、文件、章节、行号、摘录）与错误信息。
- 引用通过版本固定的 `/knowledge/versions/{version_id}/sources/{snippet_id}` 打开，旧回答不会改指新内容。
- 前端不持有密钥；密钥只在后端进程。

## 限制

1. 问答只使用当前已发布版本覆盖的原文；未整理的资料不参与。要覆盖整个课程，需要 03/08 把相应范围整理发布。
2. 概念路由可能选中弱相关概念；回答仍须自行说明资料不足。程序只校验 id 与范围，不判断语义相关性。
3. 引用合法只证明可定位，不证明结论在语义上受原文支持；语义核对仍需人工样本。
4. SSE 为一次性请求，不提供断线续传；客户端中止会把回答标为 `interrupted`。
5. 拓展解释（06）尚未实现；“资料外补充”不会被自动加入课程知识。
6. 个人笔记（05）与更新后历史保留（11）尚未实现；11 还依赖 A 的 08。
