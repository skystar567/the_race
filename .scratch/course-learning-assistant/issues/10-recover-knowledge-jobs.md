# 10: 在故障或重启后继续知识整理任务

**What to build:** 学生看到任务失败原因，能够重试；工作进程中断后可继续未完成整理，已有课程知识保持可用。

**Blocked by:** 08：追加资料并一致发布新的课程知识

**Status:** ready-for-agent

- [x] 首次整理和追加整理均持久保存任务与步骤结果；一次只执行一个知识整理任务，其他任务的等待和执行状态可查询。
- [x] 工作进程重启后复用已保存的成功结果，继续未完成工作；学生有可用的失败说明与重试操作。
- [x] 对可重试模型错误采用有限重试，请求或配置等不可重试错误明确失败；空输出、截断和校验失败不被误判成功。
- [x] 模型已处理但结果尚未保存时允许再次调用，不承诺外部请求恰好执行一次；恢复或重复重试不能重复发布同一任务的知识。
- [x] 更新失败或重启期间旧版本仍能读取，首次失败不显示已有可用知识，原始资料保持完整。
- [x] 通过可控错误和实际工作进程中断验证首次及增量任务恢复、已保存结果复用与不重复发布；从界面核查状态和重试结果。
