# 09: 区分易混概念并展示资料冲突

**What to build:** 学生追加表述不同或相互矛盾的资料后，能看到正确整合的同一概念、保持区分的同名概念，以及保留双方出处的冲突说明。

**Blocked by:** 08：追加资料并一致发布新的课程知识

**Status:** ready-for-agent

- [x] 结合定义、上下文和资料依据识别同义概念，不因名称不同就重复建概念，也不因同名就强行合并。
- [x] 无法确定是否相同的候选保持独立并在图谱或页面上标记待核对；已确认的概念身份与原有关系保持可追踪。
- [x] 真实冲突保留各方表述、适用语境及出处，页面和变化摘要可见；措辞不同但不矛盾的说明不机械标为冲突。
- [x] 更新仍经候选版本校验与一致发布，原始证据不被覆盖；学生可以打开各方原文判断。
- [x] 通过追加资料操作覆盖同义异名、同名异义、语境不同、不确定及真实矛盾样例；可控样例验证稳定行为，并核查真实模型整合结果。
