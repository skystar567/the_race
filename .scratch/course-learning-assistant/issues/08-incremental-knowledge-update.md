# 08: 追加资料并一致发布新的课程知识

**What to build:** 学生加入一份短 Markdown，看到已有概念被补充或新概念出现；整理期间可继续阅读旧知识，成功后各知识视图一起更新。

**Blocked by:** 03：按整理范围浏览章节与跨章节知识

**Status:** ready-for-agent

- [ ] 追加资料经真实 Flash 流程处理，在含义明确且无冲突的样本中补充已有概念或新增知识点，保留原始资料及出处。
- [ ] 确认是同一概念时沿用稳定标识，名称或别名变化不重新分配身份；同名本身不能作为合并依据，无法确认的候选先独立保留并标记。
- [ ] 构建候选版本，通过引用、关系和页面一致性校验后才切换当前版本，保留旧版本及来源；图谱、详情和引用不会读取半完成的新知识。
- [ ] 整理期间旧知识可浏览，成功后显示新增与补充摘要；失败保留原有已发布知识并显示失败状态。
- [ ] 未纳入整理范围的内容仍然明确标示；更新任务不能绕过原有受控流程和课程隔离。
- [ ] 以真实短资料验证更新前后的页面、概念身份及引用变化；通过受控失败验证无效候选不发布。跨来源冲突展示、任务恢复和问答笔记并发另有后续任务。
