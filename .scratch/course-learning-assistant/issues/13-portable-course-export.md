# 13: 导出可独立阅读的课程资料包

**What to build:** 学生导出当前课程，在应用之外阅读知识页面、关系索引、个人笔记与原始 Markdown，并继续核查包括旧笔记在内的来源。

**Blocked by:** 06：主动获取拓展解释并保留来源标记；09：区分易混概念并展示资料冲突；11：知识更新时保留问答依据与个人笔记

**Status:** ready-for-agent

- [ ] 界面提供当前课程导出入口，资料包包含知识页面、关系索引、个人笔记及已导入原始 Markdown，不混入其他课程。
- [ ] 固定本次导出采用的知识版本、笔记和原文内容，即使导出期间发布新版本或保存笔记，包内也保持一致。
- [ ] 页面间使用可用的相对链接，原文引用可定位；历史笔记引用所需的原始依据一并收齐，不能仅保留当前版本需要的证据。
- [ ] 个人编辑、模型拓展标记、冲突各方出处和推断属性保留；缺失图片继续明确标记，不承诺恢复。
- [ ] 实际打开导出包核查正文和所有应存在的页面、关系与来源链接；通过导出操作验证并发更新下的一致性及课程隔离。
