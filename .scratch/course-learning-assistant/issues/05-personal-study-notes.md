# 05: 生成、编辑并保存个人笔记

**What to build:** 学生把知识点、解释或问答生成个人笔记，加入自己的理解并保存，重新打开后仍可查看正文及原文依据。

**Blocked by:** 04：在明确课程范围内进行带依据问答

**Status:** ready-for-agent

- [x] 可从选定知识点、资料内解释或已完成回答生成个人笔记，生成调用统一使用 deepseek-flash。
- [x] 学生可编辑和保存 Markdown 正文，重新读取或重启后保留个人修改；笔记按课程归属，课程切换不混用笔记。
- [x] 每份笔记保留关联知识版本和原文引用，学生能从笔记打开当时依据。
- [x] 个人笔记独立于自动维护的知识点页面保存；编辑笔记不直接改写课程知识。
- [x] 经生成、保存、再读取和打开引用验证正文及来源；用浏览器确认从知识或回答进入笔记编辑的完整操作。跨版本更新提示与并发保存由后续任务验收。
