# 14: 构建真实演示课程并核查代表问题

**What to build:** 演示者通过真实处理流程生成约定教材范围的课程，现场导入留出的短资料，并能依据已核对的教材问题展示回答表现。

**Blocked by:** 04：在明确课程范围内进行带依据问答；09：区分易混概念并展示资料冲突

**Status:** ready-for-agent

- [ ] 演示总体范围覆盖操作系统教材第 2 章及第 3 章 3.5—3.8 节，从中留出短片段作现场增量；基础构建与增量范围清晰且不将未整理章节冒充完成。
- [ ] 预构建由真实 deepseek-flash 流程产生，提供可重新构建的操作；增量材料保留真实教材出处，不伪称为教师新发材料。
- [ ] 在浏览器完成预构建课程打开、跨章节浏览、真实增量和更新后问答，确认材料实际改变知识及相关来源。
- [ ] 准备约 20 个代表问题，为每题记录可接受要点与支持位置或资料不足原因，覆盖定义、对比、别名和模糊表达、跨知识点及缺少依据。

- [ ] 记录实际回答结果、召回问题、处理耗时及材料限制；修正本范围内暴露的验收问题并重查相关样例，不用静态答案掩盖模型表现，不承诺未测性能。
