# 12: 提交问题反馈并回查资料纠错

**What to build:** 学生针对知识点或关系说明问题，查看系统回查原文和重新整理的结果，同时保留自己的笔记与历史依据。

**Blocked by:** 09：区分易混概念并展示资料冲突；11：知识更新时保留问答依据与个人笔记

**Status:** ready-for-agent

- [ ] 可从知识点或关系发起带目标的问题反馈，看到对应整理任务及处理结果。
- [ ] 反馈引导系统回查资料并重新整理相关范围，不直接被写成新的教材事实，也不允许任意编辑整张图谱。
- [ ] 处理得到的候选知识按现有规则校验和发布；冲突与待核对内容继续保留出处，反馈不能绕过来源约束。
- [ ] 分别表达任务执行状态和问题解决情况；证据不足、无变化或未解决时不得仅因任务完成声称已经修正。
- [ ] 反馈处理不覆盖个人笔记，相关依据变化提示与历史引用仍可使用。
- [ ] 从界面提交可纠正、无法由资料支持和仍存在冲突的样例，通过读取新知识、反馈结果与旧笔记验证完整行为。
