# 11: 知识更新时保留问答依据与个人笔记

**What to build:** 学生在整理期间继续提问和编辑笔记，新知识发布后仍能打开旧回答与旧笔记的原文，相关依据变化时收到检查提示。

**Blocked by:** 05：生成、编辑并保存个人笔记；08：追加资料并一致发布新的课程知识

**Status:** ready-for-agent

- [ ] 在新版本发布的同时，已开始的问答继续固定其知识版本；关联的图谱、详情和来源不会混读不同版本。
- [ ] 更新后旧回答和个人笔记仍能打开当时原文，引用不会悄悄改指新内容。
- [ ] 整理或发布期间保存的个人修改仍保留，自动更新知识页面不覆盖笔记正文；失败也不损坏个人成果。
- [ ] 仅在相关依据发生变化时提示学生检查笔记，保留个人正文由学生决定是否调整，不能把所有笔记一律视为过期。
- [ ] 通过受控发布时机和界面流程验证流式问答中发布、笔记保存中发布、更新失败与历史引用读取；检查课程间不产生错误提示。
