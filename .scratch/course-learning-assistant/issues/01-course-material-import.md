# 01: 创建课程并导入可追溯的学习资料

**What to build:** 学生在本机创建和切换课程，导入真实教材 Markdown，浏览章节与原文，重启后继续读取已保存资料。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 按已选 React、TypeScript、Vite、Python、FastAPI 和 SQLite 技术建立可运行的本机应用，数据独立持久保存；依赖版本经验证锁定，前端类型检查和构建均可执行。
- [x] 学生可创建至少两门课程、分别导入 Markdown 并重新打开资料；课程之间的资料互不混用，无需登录，服务仅供本机访问。
- [x] 从约定的操作系统教材范围选取真实小节，保留教材名称、章节出处和原始内容；不覆盖教材原件。
- [x] 按章节编号识别现有教材的混乱标题层级，为原文片段分配稳定标识并保留原文位置；展示规范化后仍可核查原文。
- [x] 原文界面能阅读文字、选定公式和代码；缺失图片明确提示，导入状态不被表示为已经完成知识整理。
- [x] 经导入、读取和重启操作验证课程隔离、资料持久化、原文定位与缺图提示；浏览器中可完成上述操作。
