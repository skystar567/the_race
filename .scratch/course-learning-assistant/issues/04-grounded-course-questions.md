# 04: 在明确课程范围内进行带依据问答

**What to build:** 学生选择当前课程、资料或章节范围提问，逐步看到带可核查引用的回答，并清楚区分资料不足、完成和中断。

**Blocked by:** 03：按整理范围浏览章节与跨章节知识

**Status:** ready-for-agent

- [ ] 默认问答范围为当前课程，可限制资料或章节；界面始终显示当前范围，切换课程同步调整，选中知识点作为焦点而非唯一允许引用对象。
- [ ] 结合概念目录、别名、中文关键词和图谱关联检索并回查原文，覆盖进程、线程等两字词；含糊问题可由 Flash 从允许的概念目录选择，结果经标识和范围校验。
- [ ] 只用 deepseek-flash 生成回答，交互问答默认关闭思考；流式响应区分生成中、完成、中断和引用校验失败，未通过校验不能标为完成答案。
- [ ] 一次回答固定一个知识版本，关键结论能打开支持它的原文；存留回答及引用关联，便于后续版本更新后继续核查。
- [ ] 资料不足、图形缺失导致无法判断或当前检索未找到依据时如实说明；不能以检索未命中断言教材中不存在该内容。
- [ ] 应用维护问答所需上下文，前端不持有模型密钥；查看引用或提问后保留图谱位置。
- [ ] 用真实教材核查概念解释、对比、跨知识点和模糊表达问题的要点及出处；通过可控响应验证范围隔离、非法引用与流式失败。向量检索仅在实际召回缺口证明必要时另行补充。
