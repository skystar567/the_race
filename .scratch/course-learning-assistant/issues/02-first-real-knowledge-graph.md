# 02: 把一小节真实教材整理成知识图谱

**What to build:** 学生选择一小节教材发起整理，查看任务状态，成功后浏览真实生成的知识图谱、知识点页面和原文依据。

**Blocked by:** 01：创建课程并导入可追溯的学习资料

**Status:** ready-for-agent

- [x] 经统一后端适配器真实调用 deepseek-flash 的 Responses 接口，抽取与整合开启思考并使用结构化输出；凭据留在后端，可控测试响应不冒充真实演示。
- [x] 固定流程完成片段读取、候选知识抽取、概念整合、页面生成、校验和发布；资料中的指令不能改变处理规则或授权任意文件操作。
- [x] 课程知识从首次发布起就有知识版本和稳定知识点标识，模型只能引用提供的原文片段；引用文本、关系端点和允许范围均经校验。
- [x] 本机工作进程执行整理，持久保存任务身份、阶段状态、成功结果与失败原因；学生能查询进度，任务状态与可用知识状态区分。
- [x] 以 Cytoscape.js 展示章节和知识点，关系限于包含、前置和对比，清楚标记资料依据或推断；不能把章节顺序直接当作前置关系。
- [x] 学生点击知识点能阅读真实生成的页面并打开相应原文；图谱、页面和来源读取同一已发布版本，重新打开应用后数据仍在。
- [ ] 空输出、截断、无效引用或结构失败不能发布；首次整理失败明确显示没有可用知识。通过业务接口复现这些失败，并人工核对真实样本的说明与出处。
