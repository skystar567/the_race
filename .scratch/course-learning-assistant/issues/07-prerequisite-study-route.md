# 07: 围绕学习目标展示有依据的学习路线

**What to build:** 学生选择目标知识点与当前学习位置，查看前置知识顺序、图谱突出显示和安排理由，能识别路线中的不确定部分。

**Blocked by:** 03：按整理范围浏览章节与跨章节知识

**Status:** ready-for-agent

- [ ] 程序按目标及前置关系收集所需知识并排序，Flash 解释理由；包含关系和对比关系不参与前置排序。
- [ ] 界面展示学习顺序并在图谱中突出显示，理由与实际采用的知识点及关系一致，来源或推断属性保留。
- [ ] 检测目标相关范围的循环、缺口和待核对关系，仅展示可确定部分并说明限制；不把部分路线称为完整路线。
- [ ] 建议结合当前学习位置表达，但不宣称知道掌握程度，不加入短测诊断或长期复习调度。
- [ ] 通过路线接口验证链式、分支、循环、缺口和混合关系样例；以真实死锁相关内容核查理由与来源，并检查浏览器路线显示。
