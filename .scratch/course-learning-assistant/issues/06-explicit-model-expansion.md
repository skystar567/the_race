# 06: 主动获取拓展解释并保留来源标记

**What to build:** 学生主动请求资料外解释，能辨认模型补充；保存到个人笔记后这一标记仍然可见。

**Blocked by:** 05：生成、编辑并保存个人笔记

**Status:** ready-for-agent

- [x] 默认回答仍限于资料依据，只有学生主动选择后才生成拓展解释，所有调用继续使用 deepseek-flash。
- [x] 资料内结论与模型补充分清呈现，补充内容不伪装为教材事实，也不自动进入课程知识。
- [x] 含拓展解释的内容可生成并保存为个人笔记，重新打开后仍保留清晰标记和原有可用引用。
- [x] 拓展生成中断或失败时显示真实状态，不把不完整补充表示为已完成解释。
- [x] 通过界面操作及知识读取验证启用条件、标记持久化和知识未被污染；为后续导出提供能保留的补充标记。
