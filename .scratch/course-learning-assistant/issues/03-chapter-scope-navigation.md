# 03: 按整理范围浏览章节与跨章节知识

**What to build:** 学生选择多个章节整理，按章节概览展开知识点、查看跨章节关联和全图，并能清楚区分已导入与已整理范围。

**Blocked by:** 02：把一小节真实教材整理成知识图谱

**Status:** ready-for-agent

- [ ] 可从已导入资料中选择整理范围，在首次知识构建中处理多个章节；范围外内容继续显示为未整理，不能宣称整本书已完成。
- [ ] 默认显示章节概览，可展开章节、查看跨章节关联并打开全图；同一知识点可关联多个章节而不因章节不同自动重复建身份。
- [ ] 包含、前置和对比关系分别表达其含义与方向；资料依据和推断标记在不同图谱视图及知识页面中保持可见。
- [ ] 学生打开知识点、原文后返回时保留图谱位置；知识页面继续支持公式、代码和缺图提示。
- [ ] 以至少两个真实章节片段核查范围标识、跨章节概念身份和可打开引用；接口验证范围与版本，浏览器验证章节展开和位置保留。
