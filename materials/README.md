## 使用

按根目录 README 启动应用并创建课程，点击“导入 Markdown”，选择上述完整教材或短样本。建议任务 02 先使用短样本贯通真实模型处理，再扩展范围。

计划中的比赛演示范围仍为第 2 章及第 3 章的 3.5—3.8 节。完整教材的共享不表示所有章节均需整理，也不表示已生成课程知识库。

可在仓库根目录重新生成本机样本：

```sh
.venv/bin/python scripts/prepare_sample.py 'materials/textbooks/计算机操作系统（第四版）.md'
```

默认输出至 `data/samples/`。若要复现本目录中的共享样本，追加 `--output-dir materials/samples`。样本对应完整教材第 1046—1080 行；应用显示的样本行号从样本文件第 1 行开始，完整出处见 `.source.json`。
